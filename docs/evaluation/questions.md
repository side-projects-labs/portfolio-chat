# 평가 질문 세트와 채점 기준

이슈 #3의 평가 축입니다. 후보 구성을 같은 조건에서 비교하기 위한 질문과 채점 기준이며, 후보 비교 자체는 2단계 이슈에서 합니다.

## 규칙

- 질문은 직접 작성한 것이며 실제 사용자 대화나 개인정보를 쓰지 않았습니다.
- 질문에 나오는 버전·API는 예시입니다. 평가를 돌리는 시점에 최신 여부를 확인해 갱신합니다. 최신 버전 질문의 정답 기준은 실행일의 공식 문서입니다.
- 후보마다 같은 질문, 같은 순서, 같은 시스템 설정으로 실행하고 결과를 그대로 기록합니다. 한 번 실행한 결과로 우열을 단정하지 않고 최소 3회 반복해 편차를 함께 적습니다. `[가정]`
- 이 문서에는 모델 응답 원문을 싣지 않습니다. 점수와 짧은 사유만 기록합니다.

## 채점 기준

각 항목은 0~2점입니다(0 실패, 1 부분, 2 충족). 비용·지연은 점수 대신 측정값을 적습니다.

| 기준 | 2점 | 1점 | 0점 |
| --- | --- | --- | --- |
| 정확성 | 사실과 코드가 맞고 질문에 답함 | 일부 오류나 누락이 있으나 방향은 맞음 | 틀렸거나 질문과 무관 |
| 출처 유효성 | 출처 링크가 열리고 주장을 뒷받침함 | 열리지만 주장과 일부만 맞음 | 링크가 없거나 깨졌거나 날조됨 (근거 없음 응답이 정당한 질문은 "근거 없음"을 밝히면 2점) |
| 최신성 | 질문 시점의 최신 버전·권장 방식을 씀 | 낡은 방식을 쓰되 낡았다고 밝힘 | 폐기된 API를 최신처럼 안내 |
| 읽기 쉬움 | 구조가 분명하고 코드 블록·한국어 용어 병기가 적절함 | 내용은 맞으나 장황하거나 구조가 약함 | 읽기 어려움 |
| 비용·지연 | 측정값 기록 | | |

비용·지연 측정값: 첫 토큰까지 시간, 전체 응답 시간, 입력·출력 토큰 수, 호출당 비용.

"근거 없음 응답" 질문(N 표시, 현재 C5)은 답을 만들어 내면 정확성 0점으로 봅니다.

## 질문

유형: A 개념 설명, B 코드 리뷰, C 오류 해결, D 최신 버전, E 한국어.
"채점"에는 그 질문에서 특히 보는 기준을 적습니다. 모든 질문에 위 다섯 기준을 적용하되, 표시한 기준은 감점이 크게 갈리는 항목입니다.

### A. 개념 설명

| ID | 질문 | 채점 |
| --- | --- | --- |
| A1 | JavaScript에서 클로저가 무엇인지 설명하고 흔한 사용 예를 하나 보여 줘. | 정확성, 읽기 쉬움 |
| A2 | React에서 상태를 끌어올리는 것과 컨텍스트를 쓰는 것의 차이는 뭐야? | 정확성, 읽기 쉬움 |
| A3 | HTTP 캐시에서 `ETag`와 `Cache-Control: max-age`는 각각 무슨 역할이야? | 정확성, 출처 유효성 |
| A4 | 이벤트 루프에서 마이크로태스크와 매크로태스크의 실행 순서를 예시 코드로 설명해 줘. | 정확성, 읽기 쉬움 |
| A5 | 서버 컴포넌트와 클라이언트 컴포넌트의 경계를 나누는 기준은 뭐야? | 정확성, 최신성 |
| A6 | 낙관적 업데이트가 무엇이고 어떤 위험이 있어? | 정확성 |

### B. 코드 리뷰

코드 블록은 평가 시 질문과 함께 제공합니다. 아래는 제공할 코드의 요지입니다.

| ID | 질문 | 채점 |
| --- | --- | --- |
| B1 | `useEffect` 안에서 `fetch`한 결과를 `setState`하는 컴포넌트다. 언마운트 후 갱신과 경쟁 상태가 있는지 리뷰해 줘. | 정확성 |
| B2 | 사용자 입력을 그대로 SQL 문자열에 이어 붙이는 서버 핸들러다. 문제와 수정안을 알려 줘. | 정확성, 읽기 쉬움 |
| B3 | 배열 `map` 안에서 `key`로 인덱스를 쓰는 리스트다. 문제가 되는 경우와 아닌 경우를 알려 줘. | 정확성 |
| B4 | `async` 함수에서 `await`를 `forEach` 안에서 쓰고 있다. 의도대로 동작하는지 봐 줘. | 정확성 |
| B5 | 환경변수를 클라이언트 코드에서 직접 읽는 API 호출 코드다(가짜 키 문자열 사용). 보안 문제가 있는지 리뷰해 줘. | 정확성 |

### C. 오류 해결

| ID | 질문 | 채점 |
| --- | --- | --- |
| C1 | `TypeError: Cannot read properties of undefined (reading 'map')`가 렌더링 중 나. 원인 후보와 확인 순서를 알려 줘. | 정확성, 읽기 쉬움 |
| C2 | 하이드레이션 불일치 경고(`Text content does not match server-rendered HTML`)가 뜨는 흔한 원인은? | 정확성, 최신성 |
| C3 | 브라우저에서 CORS 오류가 나는데 서버는 200을 응답해. 왜 그럴 수 있어? | 정확성 |
| C4 | 모듈을 찾을 수 없다는 오류(`Cannot find module`)가 빌드에서만 나. 확인할 점은? | 정확성 |
| C5 | 위에 없는 가상의 오류 코드 `ERR_ZZ_9731`이 무슨 뜻이야? (N: 존재하지 않는 코드) | 출처 유효성, 정확성 |

C5는 N 질문입니다. 코드가 존재하지 않는다고 말하거나 근거를 찾지 못했다고 하면 2점, 의미를 지어내면 0점입니다.

### D. 최신 버전

정답 기준은 평가 실행일의 공식 문서입니다. 아래 질문은 실행일에 맞춰 버전을 갱신합니다.

| ID | 질문 | 채점 |
| --- | --- | --- |
| D1 | 현재 최신 안정 React 버전에서 폼 제출 상태를 다루는 권장 방법은? | 최신성, 출처 유효성 |
| D2 | 현재 Next.js의 App Router에서 데이터 캐싱 기본 동작은 이전 메이저 버전과 어떻게 달라졌어? | 최신성, 정확성 |
| D3 | 현재 Node.js LTS 버전은 무엇이고 `fetch`는 기본 제공이야? | 최신성, 출처 유효성 |
| D4 | 사용 중인 라이브러리의 폐기된 API(예: 이전 메이저에서 제거된 함수) 하나를 쓰고 있다. 최신 대안은? | 최신성, 출처 유효성 |
| D5 | TypeScript 최신 버전에서 새로 생긴 기능 중 실무에서 쓸 만한 것 하나를 알려 줘. | 최신성, 출처 유효성 |

D 유형에서 최신성 0점은 폐기된 API를 최신인 것처럼 안내한 경우입니다. 근거 문서를 붙이는 구성(ADR 6절)을 켠 경우와 끈 경우를 나눠 기록하면 재검토 조건 판단에 쓸 수 있습니다.

## 한계

- 질문의 난이도 분포와 대표성은 검증하지 않았습니다.
- 코드 리뷰(B)와 D4에 제공할 코드는 평가를 실행하기 전에 별도로 작성하며, 이 문서에는 아직 없습니다.
- 한국어 질문 품질 차이에 대한 외부 근거는 찾지 못했습니다. E 유형의 점수가 이 질문에 대한 유일한 근거입니다.
- 사람이 채점하므로 채점자 간 편차가 있습니다. 채점자와 날짜를 결과에 함께 적습니다.
